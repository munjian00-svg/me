# moonjian
안녕하십니까, 저는 문지안이라고 합니다. 저는 대학 시절 제1전공으로 철학을 전공하였고, 그중에서도 논리를 분석하고 체계화하는 학문인 논리학에 관심이 있었습니다.
논리학을 쉽게 설명할 수 있는 예시가 있습니다. "비가 오면 땅이 젖는다. 지금 땅이 젖어 있다. 그러므로 비가 왔다."라는 문장에서 땅이 젖은 이유는 누군가 물을 뿌렸을 수도 있고, 수도관이 터졌을 수도 있기 때문입니다. 그렇기 때문에 이 결론은 반드시 참이라고 보장할 수 없습니다.
또한 이를 논리학에서는 '후건 긍정의 오류'라고 합니다. 이처럼 무언가의 논리를 분석하여 허점을 찾는 학문적 과정이, 마치 어려운 문제의 답을 찾아내는 탐구처럼 느껴져 흥미를 느끼게 되었습니다.
이를 기반으로 요즘 시대의 화두인 AI와 연관 지어 연구해보고 싶다는 생각이 들었습니다. 구체적인 주제는 'AI가 해석하기 어려운 문장을 접했을 때, 단정적으로 답을 내리는 것이 아니라 여러 가지 논리적 오류의 가능성을 제시하며 사용자에게 대답할 수 있을까?'입니다. 예를 들어 "00 오류입니다"라고 단정 짓는 대신, "00 오류와 ## 오류 중 하나로 해석될 여지가 있으나, 명확히 구분하기는 어렵습니다"라고 답변하는 방식입니다.
제가 지금까지 보아온 AI는 질문에 대해 늘 명확한 답을 내려주는 형식이었습니다. 그래서 저는 애매한 문제에 대해 부정확한 답을 내릴 가능성이 있는 AI의 한계를 연구 주제로 삼고 싶었습니다. 5년 뒤 저는 이 연구의 해답을 찾아, 제가 목표로 하는 마케팅 분야에 AI를 통합하여 사람들의 마음을 더 강력하게 끌어당기는 마케팅을 실현해보고 싶습니다.
